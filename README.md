# Credit Risk XAI — Explainable AI Credit Risk Assessment System

> ⚠️ **Disclaimer:** All outputs are for **educational and research purposes only**.
> This system must NOT be used for real lending decisions. Results do not constitute
> financial, legal, or credit advice.

---

## Overview

An end-to-end modular credit risk system that:

- **Trains** three classifiers (Logistic Regression, Random Forest, XGBoost) on LendingClub-style data
- **Explains** predictions globally (SHAP beeswarm / bar plots) and locally per applicant (waterfall, LIME)
- **Generates** counterfactual scenarios showing minimal changes to flip a prediction from Default → Fully Paid
- **Audits** fairness by age group using Fairlearn (FNR, FPR, demographic parity)
- **Serves** a FastAPI REST endpoint returning probability, risk category, SHAP factors, counterfactuals, and fairness metrics
- **Visualises** everything in a React dashboard with risk gauge, SHAP chart, counterfactual table, and fairness panel

## Setup & Run

### Prerequisites

- Python 3.10+
- Node.js 18+

---

### 1. Install Python Dependencies

```bash
cd credit_risk_xai/backend

# Create and activate a virtual environment (recommended)
python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # macOS/Linux

pip install -r requirements.txt
```

---

### 2. Train the Model

```bash
# From backend/ directory (with venv active)

# Option A: Use synthetic data (default — no CSV required)
python train.py

# Option B: Point to a LendingClub CSV
python train.py --csv path/to/lending_club.csv --output-dir models
```

Training takes ~2–5 minutes and generates:
- `models/best_model.pkl` — calibrated best model
- `models/metrics.json` — ROC-AUC, F1, Brier score
- `models/fairness.json` — FNR/FPR by age group
- `models/shap_summary_bar.png` — global SHAP bar chart
- `models/shap_beeswarm.png` — SHAP beeswarm plot
- `models/calibration_curve.png` — reliability curve

---

### 3. Start the FastAPI Backend

```bash
# From backend/ directory
uvicorn api:app --reload --port 8000
```

Test the API:

```bash
# Health check
curl http://localhost:8000/health

# Sample prediction
curl -X POST http://localhost:8000/predict \
  -H "Content-Type: application/json" \
  -d @sample_input.json

# Interactive Swagger UI
# Open http://localhost:8000/docs
```

---

### 4. Start the React Frontend

```bash
cd credit_risk_xai/frontend

npm install
npm run dev
```

Open **http://localhost:5173** in your browser.

The Vite dev server proxies `/api/*` → `http://localhost:8000`.

## Feature Engineering

| Feature | Formula | Effect |
|---|---|---|
| `dti` | `existing_debt / annual_income` | High → more stress |
| `lti` | `loan_amount / annual_income` | High → larger burden |
| `payment_burden` | `installment / (annual_income/12)` | High → tight cash flow |
| `savings_ratio` | `savings / annual_income` | High → protective |
| `income_expense_surplus` | `monthly_income - monthly_expenses` | High → protective |

## Risk Thresholds

| Probability | Category |
|---|---|
| < 30% | 🟢 Low Risk |
| 30% – 60% | 🟡 Medium Risk |

## Notes

- If `dice-ml` fails, the system automatically falls back to a greedy **perturbation search** counterfactual.
- SHAP uses `TreeExplainer` for RF/XGB and `LinearExplainer` for Logistic Regression.
- The API loads model artifacts on startup — always run `train.py` before `api.py`.
- SHAP local explanations in the API require a live model and may take 1–3 seconds per request.
